# T0.2 Three-phase power refresher

Five solved problems that rebuild the plan's worked example: 32.1 A per AC charger, about 92 A
per DC charger, and 73 % loading on a 250 kVA transformer.

## Key ideas

- **The sizing chain is P → S → I.** The charger's datasheet gives real power, but cables,
  breakers and the transformer only care about current, and current follows apparent power.
- **400 V is line-to-line.** Each phase-to-neutral voltage is 400/√3 = 230.9 V. The "230 V" in
  "400/230 V" is the same number, rounded.
- **S = √3 · U · I** with U as the line voltage and I as the line current. This holds for both star
  and delta, so I don't need to know how a load is wired inside to find the current it draws.
- **P = S · cosφ, Q = S · sinφ, S² = P² + Q².** The power triangle. PF = cosφ = P/S.
- **Design current:** I = P / (√3 · U · cosφ). Low PF or low efficiency means more current for
  the same useful power.

|               | Star (Y)        | Delta (Δ)        |
| ------------- | --------------- | ---------------- |
| Line voltage  | U = √3 · U_ph   | U = U_ph         |
| Line current  | I = I_ph        | I = √3 · I_ph    |

All five problems assume a balanced load, so the neutral current is about zero.

## Problem 1: one 22 kW AC charger

**Given:** P = 22 kW, U = 400 V, PF = 0.99. **Find:** I, S, Q.

```
I   = P / (√3 · U · PF) = 22 000 / (1.732 · 400 · 0.99) = 22 000 / 685.9 = 32.1 A
S   = P / PF            = 22 / 0.99                                     = 22.2 kVA
φ   = arccos(0.99)      = 8.11°,  sin φ = 0.141
Q   = S · sin φ         = 22.2 · 0.141                                  = 3.1 kvar
```

**Check:** √(22.0² + 3.1²) = 22.2 kVA ✓. Also S / (√3 · 400) = 22 222 / 692.8 = 32.1 A ✓.

**Takeaway:** 32.1 A sits just above the 32 A rating of a "22 kW, 32 A" wallbox. The 22 kW
label is nominal (√3 · 400 · 32 = 22.17 kVA at unity PF). The breaker and cable must be sized
on the current, not the kW label.

## Problem 2: star vs delta, three 20 Ω resistors on 400 V

**Star.** Each resistor sees phase voltage.

```
U_ph = 400 / √3     = 230.9 V
I_ph = I_line       = 230.9 / 20        = 11.5 A
P    = 3 · I² · R   = 3 · 11.55² · 20   = 8.0 kW
```

**Delta.** Each resistor sees the full line voltage.

```
U_ph   = 400 V
I_ph   = 400 / 20       = 20.0 A
I_line = √3 · 20        = 34.6 A
P      = 3 · I_ph² · R  = 3 · 20² · 20   = 24.0 kW
```

**Check** with S = √3 · U · I (PF = 1 for resistors): star 1.732 · 400 · 11.55 = 8.0 kW ✓,
delta 1.732 · 400 · 34.64 = 24.0 kW ✓.

**Ratio:** delta draws **3×** the power and 3× the line current of star. Each resistor's voltage
goes up by √3 and P ∝ U², so the power goes up by (√3)² = 3.

**Takeaway:** this is why star-delta starting works for motors: start in star at a third of
the inrush, then switch to delta. For sizing, the wiring changes the load, but
S = √3 · U · I_line still gives the right answer from the terminals.

## Problem 3: a motor-type load, 50 A at PF 0.8 lagging

**Given:** I = 50 A, U = 400 V, PF = 0.8 lagging. **Find:** S, P, Q.

```
S = √3 · U · I = 1.732 · 400 · 50 = 34.6 kVA
P = S · 0.8                      = 27.7 kW
Q = S · 0.6                      = 20.8 kvar     (sin φ = √(1 − 0.8²) = 0.6)
```

**Check:** 3-4-5 triangle: 27.7² + 20.8² = 34.6² ✓.

**Stretch: capacitors to reach PF 0.95.** Capacitors supply Q locally, so P stays the same
and only Q has to come down.

```
φ_new  = arccos(0.95)        = 18.19°,  tan φ_new = 0.329
Q_new  = P · tan φ_new       = 27.7 · 0.329    = 9.1 kvar
Q_C    = Q_old − Q_new       = 20.8 − 9.1      = 11.7 kvar
```

**Effect on current:** S_new = 27.7 / 0.95 = 29.2 kVA, so I_new = 29 170 / 692.8 = 42.1 A.
The same 27.7 kW of work now takes 42 A instead of 50 A, a 16 % cut in current and about 29 %
less I²R loss in the feeder.

**Takeaway:** "low PF means more current for the same real power" in numbers. EV chargers
already run at PF ≈ 0.99, so compensation matters little for this hub. It matters for
motor-heavy sites, such as the kiosk HVAC if it turns out to be large.

## Problem 4: one 60 kW DC charger

**Given:** P_out = 60 kW (to the battery), efficiency η = 95 %, PF = 0.99. **Find:** grid
input P, S, I.

```
P_in = P_out / η          = 60 / 0.95                        = 63.2 kW
S    = P_in / PF          = 63.2 / 0.99                      = 63.8 kVA
I    = P_in / (√3·U·PF)   = 63 158 / (1.732 · 400 · 0.99)    = 92.1 A
```

The 3.2 kW difference between P_in and P_out is heat in the rectifier and DC/DC stages. That
heat is a cooling load for the cabinet, not something the grid "sees" differently.

**Takeaway:** the nameplate 60 kW is DC output. The grid side is always larger, so
efficiency **and** PF both have to be divided out before sizing anything upstream. This
matches the plan's "about 92 A".

## Problem 5: the whole hub, unmanaged

**Given:** 2 × 22 kW AC (PF 0.99), 2 × 60 kW DC (η 95 %, PF 0.99), 10 kW auxiliary at an
assumed PF 0.95. **Find:** total P, S, I and loading of a 250 kVA transformer.

**Method: sum P and Q per load, then rebuild S.** Currents and apparent powers are magnitudes of
phasors at different angles, so adding them directly is only an approximation.

| Load            | Qty | P each (kW) | PF   | S each (kVA) | Q each (kvar) | P total (kW) | Q total (kvar) |
| --------------- | --: | ----------: | ---: | -----------: | ------------: | -----------: | -------------: |
| AC charger      |   2 |       22.00 | 0.99 |        22.22 |          3.13 |        44.00 |           6.27 |
| DC charger      |   2 |       63.16 | 0.99 |        63.80 |          9.00 |       126.32 |          18.00 |
| Auxiliary       |   1 |       10.00 | 0.95 |        10.53 |          3.29 |        10.00 |           3.29 |
| **Total**       |     |             |      |              |               |   **180.32** |      **27.56** |

```
S_total = √(180.32² + 27.56²)  = 182.4 kVA
PF_hub  = 180.32 / 182.4       = 0.989
I       = 182 409 / (√3 · 400) = 263.3 A per phase
Loading = 182.4 / 250          = 73.0 %
```
